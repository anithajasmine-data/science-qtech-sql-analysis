# Science Q-Tech SQL Analysis

## Project Overview
This project demonstrates SQL-based analysis of employee and project-related datasets using MySQL. It focuses on exploring employee information, analyzing salaries, performance ratings, experience, and departmental data.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Datasets
- `emp_record_table.csv` — Employee records
- `data_science_team.csv` — Data science team information
- `proj_table.csv` — Project-related information

## SQL Concepts Demonstrated
- SELECT and WHERE
- Aggregate functions: MIN, MAX, AVG, COUNT
- GROUP BY and ORDER BY
- UNION
- Subqueries
- Window functions: RANK and MAX OVER
- Views
- Employee salary and performance analysis

## Analysis Objectives
1. Analyze employee performance ratings.
2. Compare minimum and maximum salaries across job roles.
3. Rank employees based on experience.
4. Examine employees across departments.
5. Calculate employee bonuses using salary and ratings.
6. Analyze average salaries across continents.

## Project Files
- `science qtech project.sql` — SQL analysis queries
- Three CSV files containing project datasets
